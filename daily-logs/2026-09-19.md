## Notes

- Codex is currently in free tier
- Predictive agent4drone baseline:
- Uses normal Agent4Drone tools and reasoning
- Adds a speculative predictor that asks the LLM for the next 1-3 tool actions plus confidence
- If confidence is above threshold, it executes those cached actions directly
- If confidence is low or invalid, it falls back to normal Agent4Drone
- Rejected predictions are still logged in intermediate_steps and token usage, so latency/token accounting stays honest
```
export PREDICTIVE_AGENT4DRONE_CONFIDENCE_THRESHOLD=0.85
export PREDICTIVE_AGENT4DRONE_MAX_ACTIONS=3
export PREDICTIVE_AGENT4DRONE_WAIT_TIMEOUT=12.0
```
