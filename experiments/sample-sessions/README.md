# Sample Sessions

These are copied starter sessions from:

```text
server/config/example/
```

Each sample is stored in the same format recommended for real experiment folders:

```text
sample-sessions/
└── target-assignment/
    ├── notes.md
    ├── session_export.json
    ├── result_export.json
    └── screenshots/
```

## Available Samples

- `example-session/`
- `area-search/`
- `area-assignment-and-patrol/`
- `target-assignment/`
- `target-tracking/`

## Suggested First Pass

1. Pick one sample folder.
2. Import its `session_export.json` through the controller.
3. Launch the session.
4. Inspect drones, targets, obstacles, environment, and tasks.
5. Try one manual drone command.
6. Export the updated session into a new numbered experiment folder.
7. If you run AI Agent Auto-Check, export results as `result_export.json`.
8. Add screenshots and summarize the run in `notes.md`.

Keep these sample folders as clean starter inputs. Save modified runs under numbered folders in `intern-work/experiments/`.
